# AI Image Classifier

An AI-powered image classification project built with Python and PyTorch.

## 🚀 Overview

This project uses a pretrained ResNet-50 deep learning model to classify images.

The model receives an image and returns the top 5 predicted classes with confidence scores.

## 🧠 Technologies

- Python
- PyTorch
- TorchVision
- ResNet-50
- Pillow

## 🔄 Pipeline

Image
↓
Image Preprocessing
↓
ResNet-50
↓
Neural Network Prediction
↓
Softmax Probabilities
↓
Top 5 Predictions
